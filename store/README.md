# Store assets

| File | Use |
| --- | --- |
| `tv_banner.png` | Android TV leanback banner (also `res/drawable/tv_banner.xml` ships in the APK) |
| `app_icon.png` | High-res app icon / adaptive foreground reference |
| `feature_poster.png` | 1080×1920 Play Console TV poster |

The APK uses vector `tv_banner.xml` and adaptive icons so it launches without these PNGs. Upload the PNGs in Play Console.
